Definición de módulos

A continuación, se debe elegir una de las opciones disponibles para definir los módulos del armario. Las opciones se calculan en función de la anchura, altura y profundidad de la estructura, que han sido calculadas a partir de los parámetros globales. Para dar las opciones disponibles, se parte de los siguientes parámetros de la estructura del armario:

  • Anchura estructura: {{ estudio.dimensiones.anchura_estructura }} mm ({{ estudio.dimensiones.anchura }} − 2 × {{ estudio.constantes.distanciaEsquina }}) ({{ estudio.dimensiones.anchura }} − {{ estudio.constantes.distanciaEsquina }}) ({{ estudio.dimensiones.anchura }})
  • Altura estructura: {{ estudio.dimensiones.altura_estructura }} mm ({{ estudio.dimensiones.altura }} − {{ estudio.constantes.distanciaTecho }} − {{ estudio.constantes.distanciaSuelo }})
  • Profundidad estructura: {{ estudio.dimensiones.profundidad_estructura }} mm ({{ estudio.dimensiones.profundidad }} − {{ estudio.constantes.distanciaFondo }})
